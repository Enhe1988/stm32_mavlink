# 光流方向与倾斜高度实测说明

更新：2026-11-03。光流与测距的实板接收已由用户验证通过，下一步验证机体 XY 速度方向和倾斜时的离地高度。

## 观察变量

STM32 调试器展开 `flow_data`，无法定位时使用 `'mavlink_flow.c'::flow_data`。姿态展开 `imu_data`，有歧义时使用 `'INS_task.c'::imu_data`。

| 变量 | 含义 |
| --- | --- |
| `flow_data.flow_x_rad` / `flow_y_rad` | 106 原始光流角位移，rad，未做轴映射和陀螺补偿 |
| `flow_data.integration_time_s` | 106 声明的积分时间，s |
| `flow_data.flow_quality` | 光流质量，当前速度要求 ≥10 |
| `flow_data.vx_body_mps` / `vy_body_mps` | 补偿后的机体速度，m/s，前/右为正 |
| `flow_data.velocity_valid` | 速度有效位 |
| `flow_data.ground_distance_m` | 106 中沿光轴的原始斜距，m |
| `flow_data.range_cm` | 132 中的原始斜距，cm，除以 100 才是 m |
| `flow_data.height_m` / `height_valid` | 最近一次距离更新得到的垂直离地高度及有效位 |
| `flow_data.flow_frame_count` / `range_frame_count` | 两种消息的累计帧数，应持续增加 |
| `flow_data.flow_update_ms` / `range_update_ms` / `height_update_ms` | 本机接收、解算时间，ms |
| `imu_data.INS_angle[2]` / `[1]` | Roll / Pitch，度 |
| `imu_data.INS_gyro[0]` / `[1]` | 绕机体 X / Y 的角速度，rad/s |
| `imu_data.IMU_init_flag` / `update_ms` | INS 初始化状态及更新时间 |

`flow_data` 是最近发布的内部数据，Live Watch 不保证多个变量来自同一次更新，内部有效位也不会随时间自行清零。先确认帧数、时间戳持续变化。应用取数使用 `mavlink_flow_get_snapshot()`，它会另外执行 100ms 超时检查；调试观察无需在目标机反复调用函数。

上位机继续以每种数据 20Hz 接收 `ATTITUDE`、`vx_body`、`vy_body`、`height`、`telem_ok`，经现有转发链路到地面电脑 UDP 14550。`telem_ok=7` 表示全部有效，`5` 表示姿态/高度有效而速度无效。角度遥测为 rad，与内部的 deg 不同。

## 先确认姿态和距离

按实际样机安装飞控板和下视模块。`AIRCRAFT_MODEL` 决定 IMU 安装旋转，当前默认 A 为竖放；机体水平不等于把 PCB 平放。确认机体水平时 Roll、Pitch 接近 0°，单独做 Roll/Pitch 时对应角度变化。

在平坦、有纹理、照明稳定的地面上方，先选约 0.8m 高度，确认质量、原始距离和有效位合理。静止时比较 `ground_distance_m` 与 `range_cm / 100`；若两者来自同一探头，应基本一致。新发送端若输出已补偿的高度、某一路距离为 0，或两个字段具有不同参考点，需要先核实含义。当前接收端将两者都当作原始斜距。

106 和 132 都更新同一个 `height_m`，由较后处理的消息覆盖；速度只使用 106 自带的距离。两路距离不同会使高度在消息间跳变，不能直接归因于姿态算法。需要严格对应时，可在 `mavlink_flow_dispatch()` 发布完成后暂停，核对当前消息 ID 和局部 `next`；暂停期间的 UART 积压不用于判断实时接收性能。

## 光流方向验证

机体系为 X 前、Y 右、Z 下。保持近水平、朝向和离地高度基本不变，分别平移：

| 动作 | 预期速度 |
| --- | --- |
| 向机头平移 | `vx_body_mps > 0`，`vy_body_mps` 接近 0 |
| 向机尾平移 | `vx_body_mps < 0`，`vy_body_mps` 接近 0 |
| 向机体右侧平移 | `vy_body_mps > 0`，`vx_body_mps` 接近 0 |
| 向机体左侧平移 | `vy_body_mps < 0`，`vx_body_mps` 接近 0 |
| 静止 | 两轴接近 0，且 `velocity_valid=1` |

配置位于 `bsp/bsp_config.h`，当前 `FLOW_BODY_X_AXIS=0`、`FLOW_BODY_Y_AXIS=1`，两项 `FLOW_BODY_X/Y_SCALE=(-1.0f)`。实测轴对应正确、前移和右移的速度均为负，因此保留轴序并将两个光流角轴反号；烧录后复核四个方向和旋转补偿。这里 X/Y 是**机体绕 X/Y 的光流角轴**，不是最终平移速度轴：

```text
bx = raw[FLOW_BODY_X_AXIS] * FLOW_BODY_X_SCALE / dt
by = raw[FLOW_BODY_Y_AXIS] * FLOW_BODY_Y_SCALE / dt
vx =  (by - gyro_y) * distance
vy = -(bx - gyro_x) * distance
```

其中 `gyro_x/y` 为 `imu_data.INS_gyro[0/1]`，`raw[0/1]` 为原始 `flow_x/y_rad`。

- 前后移动主要出现在 vy、左右主要出现在 vx：先交换两个 `AXIS` 的 0/1，再重测四个方向。
- 前后速度反了：将 `FLOW_BODY_Y_SCALE` 反号。
- 左右速度反了：将 `FLOW_BODY_X_SCALE` 反号。
- 比例先保持绝对值为 1，方向确认后再用已知位移和时间验证速度大小。积分时间错误也会造成比例误差。

轴映射在减陀螺之前生效，不要只把最终速度反号。方向通过后，缓慢做尽可能绕模块光心的 Roll/Pitch 旋转：纯旋转时，映射后的光流角速度应接近对应陀螺角速度，补偿后的平移速度应接近 0。当前使用接收时角速度近似积分窗口均值；手持旋转的真实平移、杆臂和延迟也会带来残差，先排除这些影响再判断映射。

## 倾斜高度验证

当前计算为 `h = d × cos(roll) × cos(pitch)`，角度在代码中从 deg 转为 rad。假设地面水平、测距轴沿机体 +Z。h 是探头参考点离地面的垂直距离，不含探头到重心的安装偏移；这是姿态投影，尚未融合加速度、气压计，也未进行高度滤波。

保持**探头参考点的实际垂直高度**不变，用固定支点或定位夹具缓慢倾斜，每个角度静止后记录几秒。仅保持手或机体中心不动，可能使探头上下移动，不能用于判断补偿误差。

以真实探头高度 H=0.800m 为例：

| Roll | Pitch | 预期原始斜距 d | 预期补偿高度 h |
| --- | --- | --- | --- |
| 0° | 0° | 0.800m | 0.800m |
| ±10° | 0° | 0.812m | 0.800m |
| ±20° | 0° | 0.851m | 0.800m |
| ±25° | 0° | 0.883m | 0.800m |
| 0° | ±20° | 0.851m | 0.800m |
| ±20° | ±20° | 0.906m | 0.800m |

理想情况下倾斜越大，斜距增大，补偿高度基本不变。先测单轴正负角，再测双轴。当前 `FLOW_MIN_TILT_COS=0.8660254` 限制的是 `cos(roll)×cos(pitch)`，即合成倾角约 30°；双轴各 25°已超范围。首轮用单轴不超过 25°、双轴各 20°，避免在 30°边界判断浮点有效性。

|  |  |  |  |  |  |  |  |  |

先以多个静止样本的平均高度计算 `height−H`，再比较正负倾角误差和静止波动；第一轮记录实际误差，不预设传感器精度已达标。若仍随倾角明显变化，依次检查 INS 水平零位、探头是否上下移动、两路距离是否一致且都为斜距、光轴安装、地面与光斑落点、静止距离噪声。保留原始数据，暂不靠加滤波掩盖系统性误差。

当前输入范围仍为 0.08–4m、积分时间 5–50ms、quality≥10、合成倾角约≤30°；无效结果遥测发送 NaN。方向和几何验证通过后，再处理速度比例、动态旋转补偿与高度融合。光流/高度目前均未进入控制闭环。
